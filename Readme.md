# Week 1 Networking Fundamentals

This repository contains my Week 1 assignment for the DG Interns Hub Cybersecurity Internship. The objective of this assignment was to understand the fundamentals of computer networking through both theoretical concepts and practical implementation.

## Objective

The main objective of this assignment was to:

- Learn the OSI Model and TCP/IP Model.
- Understand common networking protocols.
- Learn IP addressing and subnetting basics.
- Practice basic networking commands.
- Build a simple network using Cisco Packet Tracer.

## Topics Covered

### OSI Model

- Physical Layer
- Data Link Layer
- Network Layer
- Transport Layer
- Session Layer
- Presentation Layer
- Application Layer

### TCP/IP Model

- Network Access Layer
- Internet Layer
- Transport Layer
- Application Layer

### Networking Protocols

- HTTP
- HTTPS

### IP Addressing

- IP Address
- Public and Private IP Address
- Basic Subnetting

## Practical Work

### Networking Commands

The following commands were executed:

```bash
ping google.com
ipconfig
tracert google.com
```

### Cisco Packet Tracer

Created a simple network topology consisting of:

- PC
- Switch
- Router

Configured the following:

- PC IP Address: 192.168.1.10
- Subnet Mask: 255.255.255.0
- Default Gateway: 192.168.1.1
- Router IP Address: 192.168.1.1

Verified the network by successfully running:

```bash
ping 192.168.1.1
```
